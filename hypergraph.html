Real Tensor

HyperGraph

This TensorSuite collection includes tensors from hypergraph workloads published on https://www.cs.cornell.edu/~arb/data/, where interactions involve more than two nodes simultaneously. Each dataset is represented across multiple tensor orders, from 2D up to higher dimensions depending on the dataset.

coauth-DBLP

A higher-order network built from DBLP publications, where nodes are authors and each simplex represents a co-authored publication. Timestamps are not considered; only unique simplices are retained during construction. Simplices are restricted to at most 25 nodes [1], while 1D means singletons. Please also cite [1] when using these tensors.

A summary JSON file is provided for all the 1D–25D tensors here, with dimension size 1,930,378 for all tensors.
